# React Calendar Application for Communication Tracking

## Branch: `feature-calendar-module`

### Features Implemented:
- **Admin Module**:
  - Company Management: Add, edit, and delete companies with attributes like name, location, LinkedIn profile, emails, phone numbers, and communication periodicity.
  - Communication Method Management: Define communication methods with a sequence, mandatory flag, and default values.

- **User Module**:
  - Dashboard: View communication statuses with color-coded highlights for overdue, due, and completed tasks.
  - Notifications: Grid for overdue and due communications with a notification badge.
  - Calendar View: View past and upcoming communications with interaction logging.

- **Optional Analytics Module**:
  - Reports on communication frequency, engagement effectiveness, and overdue trends.
  - Export options for PDF and CSV.

### Setup Instructions:
1. Clone the repository:
   ```bash
   git clone https://github.com/rajeshjakka16/ReactCalenderTask.git
   ```
2. Switch to the branch:
   ```bash
   git checkout feature-calendar-module
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm start
   ```
